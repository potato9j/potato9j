### 🌐 About Me

* **Background**: 2017년(14세) 코딩을 시작하여 프론트엔드를 기반으로 Node.js 백엔드 및 웹 보안 영역으로 기술을 확장해 왔습니다.
* **Specialty**: 인터랙티브 데이터 시각화 웹 애플리케이션 구축, 견고한 풀스택 아키텍처 설계, 시스템 안정성 분석
* **Philosophy**: 사용자가 직관적으로 이해할 수 있는 UI를 설계하고, 백단에서는 견고하고 안전한 데이터 파이프라인을 구축합니다.
